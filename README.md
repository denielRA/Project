# Convertidor de Imágenes (HEIC a JPG/PNG/WEBP)

Aplicación portátil para Linux para la conversión rápida de imágenes HEIC a otros formatos mediante una interfaz gráfica.

---

## 🚀 Cómo reconstruir y ejecutar la aplicación en Linux

Sigue estos pasos desde la terminal para unirlo y ejecutarlo:

### 1. Unir las partes divididas
Ubícate en la carpeta donde descargaste las partes y ejecuta:

```bash
cat convertidor_parte_* > convertidor-imagenes-linux.tar.gz
tar -xzvf convertidor-imagenes-linux.tar.gz
chmod +x convertidor-imagenes
./convertidor-imagenes
